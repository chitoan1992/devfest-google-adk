## 💡 Key Design Decisions

1. **Engaging Language**: Cool and impactful, not "sến súa"
2. **Clear Progression**: Every action = visible XP gain
3. **Checkpoint System**: `game.show_stats()` at mission completion
4. **Achievement Popups**: Instant feedback for milestones
5. **Think Questions**: Embedded learning prompts marked with 🤔
6. **Bonus Challenges**: Optional content for advanced learners
